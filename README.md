# Nov 26 Monthsary Flower Date Invite

A cute, interactive flower-animated web invitation for a November 26 monthsary date.

## Features
- **Wax-Sealed Botanical Envelope:** Tap to open the envelope flap and trigger a burst of petals.
- **Blooming Flower Animations:** Unfurling SVG peony centerpiece, swaying botanical corner florals, drifting canvas petals, and tap-anywhere blooming flowers.
- **Interactive RSVP:** Playful response buttons with a celebratory flower bloom state.
- **Personalize & Share:** Click **Personalize** (or tap the date banner directly) to customize names, date, time, location, and love note, or pass URL parameters (`?to=...&from=...&date=2026-11-26&time=...&place=...&note=...`).

## Live Hosting (GitHub Pages)
1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**, select `main` and `/ (root)`, and click **Save**.
4. Share the generated GitHub Pages link with your girlfriend!
